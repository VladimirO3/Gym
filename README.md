# Gym App - ABS GYM 🏋️‍♂️

Современное мобильное приложение для фитнес-клуба, разработанное на **Kotlin** и **Jetpack Compose**. Приложение объединяет в себе функции социальной сети, магазина спортивного питания и медиаплеера.

## 🚀 Основные возможности

### 📰 Лента новостей
*   Просмотр актуальных событий зала (фото и видео).
*   **Интеллектуальная система реакций**: выбор эмодзи, динамическое отображение самых популярных реакций и их общего количества.
*   Админ-панель для публикации контента напрямую с телефона.

### 💬 Чат
*   **Мессенджер**: общение пользователей между собой и с администрацией.
*   **Система уведомлений**: всплывающие оповещения о новых сообщениях с быстрым переходом в нужный диалог.
*   Оптимизированный интерфейс ввода, защищенный от перекрытия клавиатурой.

### 🛒 Магазин спортивного питания
*   Каталог товаров с реальными фото, описаниями и ценами.
*   **Синхронизация с VPS**: корзина пользователя сохраняется на сервере и доступна после перезахода.
*   **Инструменты администратора**: возможность добавлять, удалять товары и менять фотографии/цены прямо в приложении.
*   Просмотр подробной информации о товаре на отдельном экране.

### 🎵 Аудио плеер
*   Слушайте музыку для тренировок прямо в приложении.
*   Поддержка плейлистов, непрерывного воспроизведения и режима перемешивания (**Shuffle**).
*   Таймлайн с возможностью перемотки трека.

### 👤 Профиль и настройки
*   Личный профиль с аватаром, именем и возрастом.
*   Выбор тем оформления (Светлая, Темная, Системная).
*   Смена языка интерфейса.
*   Управление IP-адресом сервера для подключения к личному VPS.

## 🛠 Технологический стек
*   **UI**: Jetpack Compose, Material Design 3.
*   **Сетевой слой**: Retrofit 2, OkHttp 4.
*   **Медиа**: Media3 ExoPlayer (видео и аудио).
*   **Загрузка изображений**: Coil (с кэшированием и оптимизацией памяти).
*   **База данных**: Room (для локального кэша).
*   **Бэкенд**: Интеграция с внешним VPS через REST API.
*   **Firebase**: Аналитика, Crashlytics.

## 📦 Настройка и запуск
1.  Склонируйте репозиторий.
2.  Откройте проект в **Android Studio Ladybug** (или новее).
3.  Настройте `google-services.json` для корректной работы Firebase.
4.  В настройках приложения (иконка шестеренки при входе) укажите IP вашего VPS сервера.

## 📁 Git и безопасность
Проект содержит настроенный `.gitignore`, который исключает:
*   Временные файлы сборки и кэш IDE.
*   Пользовательские загрузки (`uploads/`).
*   Ключи подписи и конфиденциальные данные.
*   *Примечание:* Ресурсы приложения (логотипы, иконки) включены в исключения и сохраняются в репозитории.
