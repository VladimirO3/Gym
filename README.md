# GYM Application (ABS GYM)

Android-приложение для управления фитнес-залом, синхронизированное с частным VPS-сервером.

## Основные возможности
- **Новости**: Просмотр и публикация новостей (текст + фото/видео).
- **Плейлист**: Управление музыкой в зале (ExoPlayer + кэширование).
- **Чат**: Общение между пользователями и администрацией в реальном времени.
- **Магазин**: Каталог товаров с корзиной и локальным кэшированием (Room).
- **Профиль**: Личные данные, аватар и интерактивный календарь заметок.

## Технический стек
- **Язык**: Kotlin
- **UI**: Jetpack Compose (Material 3)
- **БД**: Room (с поддержкой WAL и журналирования транзакций)
- **Сеть**: Retrofit + OkHttp (Multipart запросы, Refresh Token)
- **Медиа**: ExoPlayer (Media3), Coil (загрузка фото с Auth-заголовками)
- **Аналитика**: Firebase Analytics & Firestore

## Архитектура
Приложение следует паттерну **MVVM** (Model-View-ViewModel):
- **ViewModels**: Управляют состоянием UI и взаимодействуют с репозиториями.
- **Repositories**: Единственный источник данных (Single Source of Truth), синхронизируют Room и VPS.
- **DAO**: Интерфейсы доступа к локальной SQLite базе данных.

## Безопасность
- Использование JWT токенов для всех запросов к API.
- Автоматическое обновление токенов через `Authenticator`.
- Поддержка гостевого режима с ограниченным функционалом.

## Установка и запуск
1. Склонируйте репозиторий.
2. Укажите IP вашего VPS сервера в `NewsApiService.kt` или в настройках приложения.
3. Соберите проект через Gradle.
